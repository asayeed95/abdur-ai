## X thread

**1/** I now have two AI agents that wake up before me, read my repos, and draft the day's posts. Neither can publish a word. That last part took the most thought. (155)

**2/** The pipeline: agent reads the git log → picks a real shipped thing → drafts in my voice → drops it in Slack with APPROVE / EDIT / SKIP. If I do nothing, nothing posts. Silence means hold, not ship. (199)

**4/** The part nobody automates is the part that matters: every draft must trace to a real commit, bug, or decision. An agent that can invent milestones will — so the pipeline starts from the git log, not from a prompt that says "write something engaging." (252)
