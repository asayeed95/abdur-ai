Tokens, components and templates extracted from the abdur.ai codebase. Owner: Abdur. Last updated 2026-10-02. Rules and token table: DESIGN-SYSTEM.md.

/// Foundations

  • Foundations

    Colour, contrast, type, spacing, radius, shadow, motion.

  • Contrast test

    Every text-on-surface pair, both themes, plus the known risks.

/// Components

  • Button

    Mono, uppercase, widest-tracked actions: clay-filled primary, outlined secondary, borderless ghost.

  • Link

    Three link styles: underlined clay inline links in prose, meta links, and mono nav links.

  • Tag

    Topic tags, the three register badges, and the flagship chip.

  • StatusPill

    The four product-status pills: live, near, flight, building.

  • Card

    A surface tile that lifts and picks up a clay border on hover.

  • PostCard

    The writing-index row and the flagship card: date, register, title, dek, tags, reading time.

  • Callout

    In-post asides: the clay CTA callout, the quiet aside, and the register status note.

  • CodeBlock

    Inline code and the fenced block, both on surface with a hairline border.

  • NewsletterForm

    Email capture with the four states the code renders: idle, submitting, success, error.

  • NavBar

    The fixed top bar: brand with the pulsing clay dot, six mono links, theme toggle, Subscribe.

  • Footer

    Three-column footer with site links, contacts, and the legal strip.

  • Pagination

    Previous and next post cards at the foot of an article. The site has no numbered pagination.

  • EmptyState

    What a list shows when it has nothing to list, built only from existing pieces.

  • ThemeToggle

    The tri-state theme pill: Auto, then Light, then Dark, with the resolved theme always shown.
