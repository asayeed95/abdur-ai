Contrast test

Reads the live --c-* values from tokens/colors.css in each theme. It measures every text token on each ground it's allowed on (4.5:1), bg on clay, and the focus ring and input boundary (3:1). Then it re-checks the four risks from 1.0. Pairs on disallowed grounds are usage errors, which scripts/build.mjs rejects in app/ and components/.
