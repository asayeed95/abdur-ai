# RETRO.md — abdur.ai

Lessons a rule could have prevented, one line each, `[source: manual|auto]` tagged. This is the self-evolution log for this repo's (light) build-discipline gate. Unlike the heavier build-discipline package this project pulls from, there is no `EVOLVE.md` generalization pass wired here — that's swarm/multi-project machinery this single content site doesn't need. If entries pile up (5+), read them and decide by hand whether `PROCESS.md` or `scripts/check-phase.sh` needs a change.

- [2026-07-08] The repo had **zero** ESLint config before this retrofit, which made `npm run lint` / `next lint` block on an interactive setup prompt (`? Added `eslint.config.mjs` (flat config, `next/core-web-vitals` + `next/typescript`) so lint actually runs headlessly. A gate that can't run non-interactively isn't a gate. [source: manual]
- [2026-07-08] Wiring the lint gate immediately surfaced 15 real `react/jsx-no-comment-textnodes` hits — but every one was the locked Clay design system's intentional `///` eyebrow-text convention (e.g. `<p className="eyebrow">/// AITLDR</p>`), not an accidental code comment. ESLint's heuristic can't tell "visible copy that happens to start with `//`" from "a stray JS comment left in JSX." Fixing these by editing the JSX would have violated this repo's own hard rule (don't touch locked copy) to satisfy a *new* gate — exactly backwards. Disabled that one rule with a comment explaining why, instead of touching 15 files of locked content. Lesson for future gates in this or any locked-content repo: a lint/style gate you're introducing for the first time can produce false positives against intentional design conventions — read what it's flagging before "fixing" it, especially in a repo where content is explicitly frozen. - [2026-10-03] **A welcome-email request carried a field Resend's send-email API does not document, and the route reported success regardless.** `/api/subscribe` sent `unsubscribe: "mailto:…"` in the POST /emails body; the documented way to set that header is `headers`.
